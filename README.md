# 金坷垃 + Better Junimos 集成版

星露谷物语 1.6 mod 合集:**下载即用**——解压后把里面的文件夹全部放进 `Stardew Valley\Mods\` 就能一起运行。

## 包含(3 个 mod)

| 文件夹 | 是什么 |
|---|---|
| `BetterJunimos/` | Better Junimos **修复版**(ceruleandeep 3.1.2 性能修复,防寻路卡顿) |
| `JinKeLa/` | 金坷垃(世界名肥,50% 双倍收获,独立共存) |
| `JinKeLa_CP/` | 金坷垃数据包(物品/配方/商店/贴图) |

## 效果
- 金坷垃:与原版肥料完全共存,收获 50% 双倍
- **祝尼魔自动施肥**:小屋箱子里放金坷垃,祝尼魔会自动给没撒过金坷垃的田施肥(2 秒一轮,含温室;和 JTS 幽灵模式也兼容)

## 安装
1. 下载本仓库 ZIP,解压
2. 把 `BetterJunimos/`、`JinKeLa/`、`JinKeLa_CP/` **三个文件夹**全放进 `Stardew Valley\Mods\`
3. 启动游戏(SMAPI 启动器)

## 机制(金坷垃自动施肥)
- 每 2 秒扫描每座祝尼魔小屋半径内(含温室)的田
- 对"没撒过金坷垃"的田,从小屋输出箱取金坷垃施放(写 modData)
- 与普通肥料互不干扰;同一块田不会重复撒;已撒过不消耗
- 联机:只有主机扫描,天然安全

## 依赖
- SMAPI 4.5.1+
- 游戏 1.6.15+
- 不需要额外 mod(BJ 修复版已内置)
